# Security

This service holds the login for a Lucid account, which can reach a car's location and state, and answers as a Tesla API for TeslaMate, so security reports are taken seriously.

## Reporting a vulnerability

Report it privately through GitHub: **[Security › Report a vulnerability](https://github.com/epheterson/lucid-teslamate-bridge/security/advisories/new)**. Please do not open a public issue, discussion or pull request for it.

Include what you found, how to reproduce it, and what an attacker could reach with it. You will get an answer as soon as I can, and credit in the advisory unless you would rather not.

## Supported versions

The latest commit on `main` (and the latest image built from it). Fixes are not backported.
